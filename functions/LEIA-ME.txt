AVISOS DE PEDIDO (celular e computador)

Publicar a função (uma vez, no computador do dono):
  1) Instalar Node 22 e o Firebase CLI:  npm install -g firebase-tools
  2) firebase login
  3) Ver em Firebase > Firestore > Dados o "Local" do banco e ajustar REGIAO em functions/index.js
  4) cd functions && npm install && cd ..
  5) firebase deploy --only functions

Regras: acrescentar no Firestore (Regras):
    match /dispositivos/{t} {
      allow read, write: if dono();
    }

Android: ver docs/MEMORIA-PROJETO.md (google-services.json e segredo GOOGLE_SERVICES_JSON no GitHub).

Opções por aparelho: o app grava em dispositivos/<token> os campos n, c, x, p (tipos de aviso), som, q, qi, qf (silêncio).
Teste: o botão 'Enviar aviso de teste' cria pedidos/teste... (tipo cancel, ref 'teste'); a função manda o aviso de teste e o app apaga o documento.
Sons: www/sons/*.mp3 (copiados para res/raw do APK pelo workflow).

GIRO 360° E MÍDIA DO SITE (função "midia", v446) — configurar UMA vez
A chave do GitHub fica só no Firebase. Nenhum aparelho, nem o chat, vê a chave.
  1) GitHub > Settings > Developer settings > GitHub Apps > New GitHub App
       Nome: LaFouch Midia (qualquer nome livre) · Homepage: https://lafouch.com
       Webhook: DESMARCAR "Active"
       Repository permissions > Contents: Read and write (o resto: No access)
       Where can this be installed: Only on this account > Create GitHub App
  2) Na página do App: anotar o "App ID" (número). Em "Private keys" > Generate a private key (baixa um arquivo .pem).
  3) Menu "Install App" > Install > Only select repositories > catalogo > Install.
  4) No computador, na pasta do projeto:
       firebase functions:secrets:set GH_APP_ID      (digitar o número do App ID)
       firebase functions:secrets:set GH_APP_KEY --data-file CAMINHO/DO/ARQUIVO.pem
       firebase deploy --only functions
  5) Pronto. Apague o arquivo .pem do computador depois (ou guarde num lugar seguro). Esse tipo de chave não vence.
Teste: functions/teste-midia.js (node functions/teste-midia.js).

CÓDIGO DE CONFIRMAÇÃO POR E-MAIL (função "codigo", v450) — configurar UMA vez
A chave do Resend fica só no Firebase. Enquanto não estiver configurado, o site manda o link do Firebase.
  1) resend.com > criar conta > Domains > Add domain > lafouch.com
  2) Copiar os registros DNS que o Resend mostra (normalmente 3: MX/SPF e DKIM) para o painel do domínio lafouch.com. Esperar ficar "Verified".
  3) API Keys > Create API key (permissão "Sending access", domínio lafouch.com). A chave aparece uma vez só.
  4) No computador, na pasta do projeto (ANTES do deploy, senão o deploy falha):
       firebase functions:secrets:set RESEND_KEY      (colar a chave no terminal, nunca no chat)
       firebase deploy --only functions
     O mesmo deploy também liga as reservas de 15 min (PIX) e 30 min (Itaú).
Teste: functions/teste-codigo.js (node functions/teste-codigo.js).
